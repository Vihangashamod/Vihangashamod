### Vihanga Shamod

I build software. Mostly native macOS tools in Swift, web products, and developer utilities — things that work fast and don't get in the way.

Lately I'm thinking more about the architecture layer: how systems are designed, where decisions get made, and what makes a build hold up at scale. That's the direction I'm moving.

---

**Projects**

[**vitals**](https://github.com/Vihangashamod/Vitals) — Native Swift system monitor for the macOS terminal. Real-time CPU, GPU, memory, battery, and thermal telemetry. Zero dependencies, no sudo.

[**NetSpeed-mac**](https://github.com/Vihangashamod/NetSpeed-mac) — Menu bar network speed monitor for macOS. Uses 64-bit interface counters, filters VPN/bridge interfaces, universal binary for Apple Silicon + Intel.

[**vihanga-expenses**](https://github.com/Vihangashamod/vihanga-expenses) — Personal finance tracker for LKR. Parses HNB bank SMS alerts via regex, syncs live with Firestore, offline-capable PWA. React 18 + TypeScript.

[**mac-cleanup**](https://github.com/Vihangashamod/mac-cleanup) — One-script macOS dev cleanup. Clears Xcode DerivedData, stale simulator runtimes, VM bundles, and build caches.
